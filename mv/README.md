Open index.html in a browser (or run: python3 -m http.server). Put photos in assets/images/ using the filenames listed in js/main.js and build.py (logo.png, hero-school.jpg, etc.). Missing images show a labelled fallback. Edit content in js/main.js (projects, news, gallery). Pages are generated by build.py (python3 build.py) or edit the HTML directly.
Launch checklist: official address, phone, email, WhatsApp, vision/mission/values, headmaster message, curriculum, fees, requirements, deadlines, approved photos with parental permission.
